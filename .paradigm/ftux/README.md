# FTUX Reports

Reports generated by Nora, the first-time user experience agent.

## What Lives Here

Each file in `reports/` is a structured friction report from a simulation run.

## Report Format

Files are named `YYYY-MM-DD.md` (or `YYYY-MM-DD-slug.md` for multiple runs per day).

## Friction Types

| Type | Meaning |
|------|---------|
| `missing_coverage` | Surface doesn't explain something the user needs to know |
| `assumed_context` | Step assumes prior knowledge not established earlier |
| `undefined_term` | A term is used without being defined |
| `broken_flow` | A step leads nowhere or contradicts an earlier step |
| `buried_info` | Critical information exists but is hard to find |
| `contradictory` | Two surfaces say different things about the same thing |

## Severity

- **critical** — User cannot complete the task without external help
- **high** — User will likely give up or guess wrong
- **medium** — User will be slowed down or confused
- **low** — Minor polish opportunity
