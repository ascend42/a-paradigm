Why now

The agent loop is a commodity. What's missing sits above it.

Every harness now ships plugins, skills, hooks, subagents and worktrees. Nobody adjudicates what parallel agents produce, governs what loops spend, or checks whether memory is true. Your own tools already hold the pieces, in triplicate.

What it is

A small kernel, your own shell, and everything else swappable.

Gnomon is a local daemon you never think about, a terminal app you live in, and a set of packages that hold the parts that make it smart. Claude Code becomes a backend Gnomon drives on your subscription; your local models are a second backend, peers from day one.

Features

Everything you asked for, and the pieces you'd have missed.

Your own shell

A fast terminal app (built on pi-tui) for local and Claude sessions alike, with panes, an inbox and decision cards. Long sessions stay instant: virtualized, cached from day one.

Claude, subscription only

Claude Code runs headless on your plan. A session won't start if anything would bill API credits. API use exists only as a card you approve each time, shown in the band while active.

Local models, first class

Automations declare model: local | claude | any. Local work runs in a sandboxed child process on Ollama, llama.cpp or MLX, and asks you before ever falling back to the cloud.

Teacher → skill

When a local model fails, Claude writes the fix and a skill; the Classroom certifies it; the local model handles it next time. Your local fleet gets better on its own.

Armadas that merge

gnomon spawn 4 --contract spec/… fans out sessions in worktrees. In Warpline projects they are native from birth; disagreements become KNOTs in your inbox, never silent merges.

Specs become contracts

A spec compiles, with no LLM, into the symbols, flows, gates and tests it promises. Agents claim nodes; only the kernel certifies them. Progress is what exists and passes.

Voice, both ways

Push-to-talk, or a conversation mode you can interrupt. Speech recognition and the agent's voice run locally (Mac and Windows). Every exchange compacts into a lore-like log for the team.

Mods from day one

Views, tools, commands and keybindings as packages any agent can write: typed, tested with fixtures, installed through a card, each in its own sandboxed process.

A loop that learns

Entries earn credit only when they helped an accepted outcome. Confidence decays, contradictions become audits, and the reviewer is itself calibrated.

Budget fuse

Every spawn and turn needs a permit: tokens, dollars, GPU time and your subscription's usage window, with a reserve so the armada can't lock you out.

Tamper-evident log

One hash-chained, signed log for every session, decision and spend, anchored outside the database. Replay any session exactly.

Ready for teams

Device keys under one person, namespaced ids, org and team fields and approver policies are in the schema now, so 8.1 adds colleagues without rewriting anything.

The laws

Seven rules the code has to prove.

Each law ships with a test that tries to break it. If a number can't show its denominator, it doesn't ship.

No spawn without a permit

The budget fuse is on by default, fails closed, and only you can resume it. Fan-out is always visible.

Honesty is CI

Tests ban fabricated confidence, simulated steps and hard-coded gains. No label implies a mechanism the code lacks.

Tiny ABI

About a dozen kernel verbs. Everything else is discoverable through status.

Reversible

Install, then uninstall, leaves your repo and ~/.claude byte-identical. Learned state is kept or exported.

Nothing spends by default

Scheduled work runs only on attended events or explicit opt-in.

Trust posture

No install scripts, pinned dependencies, releases that verify, alpha never published as latest.

Subscription only

Claude runs on your plan. API credits only through a card you approve each time, never as a fallback.

Optimizations you feel

One runner instead of three; one approvals service instead of three; one scheduler instead of six. Local models absorb routine automations, so your Claude window goes to the work that needs it.

Optimizations you don't see

Every injection is logged, so context can be replayed exactly. Deterministic checks catch failures before an LLM judge is asked. The band moves only when something happens.

What it protects

Your keys live in hardware (Secure Enclave, TPM). Agents can claim work but never certify it, approve cards, or touch billing. Audio never leaves your machine.

How it operates

A day with Gnomon.

07:40

Overnight, three local automations triaged issues and drafted release notes on your GPU. One failed; Claude wrote the fix and a skill, waiting in Classroom for your nod.

09:05

You open Gnomon. One Touch ID unlocks approvals for the session. The inbox shows two cards: the new skill, and a budget question.

09:12

gnomon spawn 4 --contract spec/gnomon-runner. Four sessions take permits, attach to the Warpline fabric and claim contract nodes. The band shows each one and its spend.

10:30

Two agents named the same fuse differently. Tests pass on both; meanings disagree. A KNOT arrives, the only violet on screen. You decide in the split view.

13:15

Walking around, you hold the talk key: "What's left on the runner?" The agent answers aloud, summarizing, never reading code. You interrupt; it stops and remembers only what you heard.

16:40

Nine more nodes certified. The conversation compacts into a lore entry your team will be able to read in 8.1. Nothing spent API credits; the log proves it.

Delivery · build the proper version first

Four moves.

Move 1 · the instrument

Kernel, both backends, budget fuse and law 7, sandboxes, hardware keys, the TUI, mods, flow and constellation as clients. macOS and Windows. Probes on day one.

Move 2 · the armada

Spec-to-contract compiler, spawn with Warpline-native sessions, three-check certification, the teacher flywheel, a real field run.

Move 3 · the loop, live

Credit, decay, contradiction audits, reviewer calibration, liveness gates, the Shuttle view, Conductor as a client.

Move 4 · voice

Local two-way voice on sherpa-onnx with a Mac boost, barge-in, speaker labels, the lore-like team log. Can start alongside Move 2.

What would prove it wrong

After two weeks, more than half your real sessions still start outside Gnomon.

The first armada run on a real repo produces no KNOT, or a KNOT you couldn't decide from the card.

By week four, under a quarter of credited knowledge comes from the loop rather than seeded notes.

Install then uninstall leaves any diff behind.

Your Apple Developer ID for signing the Mac key helper (blocks hardware keys) · the Windows helper's sandbox read-denial · Anthropic's terms for distributing subscription-driven sessions in 8.1 · the remaining Atelier boards.
