# Scout: local-first conversational voice (2026-10-16)

Web research; [unverified] = single secondary source; latency figures are mostly vendor/secondary — benchmark locally before locking.

- STT: Parakeet TDT 0.6B v2/v3 is the local English default; Parakeet-EOU-120M streams with end-of-utterance. FluidAudio (Swift, CoreML/ANE, Apache-2.0, macOS 14+): ~2.5% WER batch / 4.9% streaming; streaming diarization Sortformer (~1 s, ~31.7% DER), offline pyannote CoreML (~15% DER). parakeet-mlx claims 0.2 s final for 5 s utterance [unverified]. Apple SpeechAnalyzer (macOS 26) on-device, 2.12% WER LibriSpeech clean on M2 Pro (one benchmark). Kyutai STT streaming with semantic VAD (1B 0.5 s delay). whisper.cpp/MLX Whisper mature, chunked; keep for multilingual.
- TTS: Kokoro-82M (Apache-2.0, very good, stream per sentence, ~148 ms per 3 s clip on M2 Studio [unverified]); Sesame CSM-1B (most natural, Apache-2.0 [unverified]); Orpheus 3B (Llama attribution); Kyutai TTS (streams text in); Piper now GPL-3.0; PocketTTS ~80 ms first audio [vendor]. Pick Kokoro default, CSM optional quality voice.
- Speech-to-speech: open full-duplex (Moshi-style, PersonaPlex-7B, BayLing-Duplex, Raon) has real barge-in but weak reasoning/tool use — research-grade for a coding kernel. Cloud: OpenAI gpt-realtime-2.1 ~$0.06–0.11/min (mini ~$0.02–0.05); Gemini Live ~$0.005/min in, $0.018 out (3.8 pricing disputed); ElevenLabs Agents ~$0.08/min + LLM. Anthropic: consumer voice mode, no official realtime audio API found — Claude via STT → Claude → TTS. All cloud realtime streams raw audio to the vendor.
- Turn-taking: Silero VAD; Smart Turn v3 (BSD-2, 8M params, semantic end-of-turn, ~3.5 ms CoreML [unverified]); barge-in = VAD + 250–400 ms min speech while TTS plays → stop playback, cancel LLM + TTS, truncate the agent turn to what was heard; macOS voice-processing AEC or headphones. Pipecat runs fully local (reference macos-local-voice-agents: Silero + Smart Turn + MLX Whisper + Gemma + Kokoro, <800 ms voice-to-voice; last push Aug 2025). LiveKit adaptive interruption is cloud-only in production. Push-to-talk safe default; wake word / conversation mode opt-in.
- Coding tools today: Claude Code /voice is one-way dictation (no spoken replies); Cursor dictation; two-way only in third-party add-ons (AgentsRoom, Olaf/voice-vibecoder, Heard). No mainstream harness has integrated local two-way voice with a durable team transcript — Gnomon's slot. (Scout did not find Odysseus as a coding tool; it is a workspace, see 01.)
- Recommended architecture: voice as a mod/client of the kernel (`gnomon-voice`, Swift for CoreML/ANE + mic/AEC, or Python Pipecat); kernel stays text-native. Budget <800 ms end-of-speech → first audio: VAD 30 ms, Smart Turn ~200 ms silence + 10 ms, Parakeet 100–200 ms, LLM TTFT (local 150–300 ms; Claude 400–900 ms), Kokoro first chunk 100–150 ms, out 20 ms. Bridge Claude latency with a local-model acknowledgement or cached filler. Speak only speakable content (summarize diffs/tool output); spoken channel separate from full text answer. Tiers: local default (FluidAudio + Smart Turn + Kokoro); cloud STT/TTS opt-in; cloud speech-to-speech opt-in per session with the kernel as tools.
- Log events: voice.turn.user {turn_id, speaker_id, t0, t1, text, asr_model, confidence, audio_ref?}; voice.turn.agent {turn_id, text_planned, text_spoken, interrupted_at_ms, tts_voice}; voice.bargein; voice.session.start/end. text_spoken vs text_planned keeps context honest after interruption.
- Lore-like transcript: compact turns at session end into a .lore-style record (speakers, decisions, tasks, symbol refs, links to raw turns); offline pyannote re-label. Speaker labels: live Sortformer clusters → enrolled local voiceprints, confirmed in the TUI; unknown = "Speaker 2".
- Privacy: raw audio, voiceprints, wake-word buffers never leave the box; raw audio not kept by default (opt-in TTL); only text to Claude; cloud audio needs a visible per-session flag + logged event; team transcripts are text-only after redaction with per-speaker consent; mic state always visible; push-to-talk default.
