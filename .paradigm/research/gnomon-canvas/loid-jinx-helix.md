# Boards panel: Loid (forge), Jinx (advocate), Helix (dx)

2026-11-23. Analysis only. Verified by the orchestrator: spec §12.7 Doodle exists (`docs/specs/gnomon.md:1517`), concept doc `docs/specs/gnomon-mods/doodle.md`, kill metric T-DDL-01 at `doodle.md:255`.

## Shared finding

Most of "boards" is already designed as Gnomon spec §12.7 **Doodle**: a shared, replayable Excalidraw sheet where every mark is a signed kernel event (`modns.doodle.op`) with host-stamped authorship (`relayedFor`), two agent tools (`doodle.view`, `doodle.draw`), redaction, `doodle:` refs, a full-text knowledge provider, compaction to lore at session end, and a kill metric (T-DDL-01: "if exports stay near zero the connection thesis is false"). None of it is built; the engine probe P12 fails on macOS CI (T-2026-11-06-003, T-2026-10-27-006).

## [Loid (forge)]

- Boards = Doodle grown up, not a new store. Two tiers: the op log stays in the kernel; the repo gets the compaction, `.paradigm/boards/<id>.board.yaml` (nodes, edges, frames, authors, refs) plus an SVG render.
- What agents learn: outcomes (stickies that became decisions, tasks, lore), acceptance (agent nodes kept vs deleted soon after; per-agent via `relayedFor`; feeds calibration per repo and mode, §8.6), gaps (nodes the founder redrew). Journaled in the Cid debrief; promoted to notebooks only after 3+ boards.
- Recall via `sym:` refs on nodes, the Doodle knowledge provider, and back-links from records citing `doodle:<ds>@<seq>`. Falsifier: a cold session asked about #X opens the board where #X was designed.
- Clutter guards: compaction prompt on boards with no export; a `tend` pass archives boards not opened or cited in 30 days; a committed board must link to at least one lore, decision or task record.

## [Jinx (advocate)]

- a-star stalled: ~259 commits in four weeks, the last month on Hive, LAN satellites, keychain and Constellation RPC rather than using the canvas. Its own GRAND-PLAN: "The trap is building the vision instead of building the tool." The canvas tried to be the OS before its learning substrate worked.
- Scope: 96 open task files tagged gnomon, including M1.3/M1.7 security conditions, helper caller verification (T-2026-10-22-004), and dogfood bugs (T-2026-10-21-006/007). A board framing approval cards on a leaky surface is a new attack surface.
- Narrow it: boards are two products. (a) a live context display (read-only view of the kernel log and Paradigm stores), which only Gnomon can do; (b) a co-authored whiteboard, about 80% covered by FigJam, tldraw, Excalidraw and artifacts. The missing 20%: signed per-agent authorship, `sym:`/`doodle:` refs, repo commits.
- Cheapest falsifier (two weeks, no new UI): agents write `.excalidraw` JSON to the scratchpad and the founder opens it in Excalidraw; pre-registered bar of 3+ boards reopened a week and 1+ decision or task a week citing a board; second arm, a static HTML context board regenerated by a hook from the kernel log. Neither reopened: thesis fails. Only the second: build (a) first.

## [Helix (dx)]

- Extend the mod ABI, don't fork it. `provides.boardNodes: [{kind, schema, view, fallback}]`; nodes render through the closed `display-block` kit (no executable content, §12.2, G-MOD-10); live widgets re-render on granted event kinds, debounced; `fallback` required (sticky with title, status, ref); the board file stores `{kind, modHash, data}`, never rendered output.
- Three agent tools: `board.open{title, seed?, from?}`, `board.view{board, since?, bounds?, as: json|png|both}` (semantic JSON first, deltas via `since`), `board.draw{board, ops[]}` with layout intents (`place: near|in|after`, `diagram: mermaid`) so the host does layout. Refusals name the field and fix. Mods add `kind` values, not tools.
- Authoring loop: `gnomon mod new --template board-node` (schema, fixture, golden renders light/dark/fallback, test); `gnomon board dev <mod>` with hot reload; a `gnomon-mod-board-node` skill in T-2026-10-20-012. Docs: "Your first board node", visible in under 10 minutes.
