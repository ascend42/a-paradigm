# Boards: Luna (Design Director), early read

2026-11-23. Analysis only, no design-system changes.

## 1. Placement on the desk
- Raising a board is an offer: a board slip under the agent's reply (`◇ board · sketch the auth handoff?`, Open / not now). Reuses the offer-slip pattern; never steals focus. Work done while closed shows as a count on the slip ("Arky added 3").
- Open: a leaf over the centre column (same move as Loops); the transcript narrows to a margin rail on the board's left.
- Full canvas ("spread"): folds the sessions rail and Workshop; header, alerts band, voice pill and stack edge stay (principle 6: kernel regions can't be hidden).
- Decisions stay in the stack; a board node links to its card, never becomes one.
- A session's boards are listed in the chat header's "more" menu and its session row.
- Dependency: the open offer-slip session `2026-10-20-gnomon-mod-invitations` must close first.

## 2. Authorship
- Colour can't carry it (the six minerals mean project). Founder's hand = solid cut paper and ink; agent work = the dashed edge principle 7 requires for model text ("agent marks never look like yours").
- Each agent has a seal: a stamped monogram on the item's pin, from the cap family. Hover/focus: `by Luna · 14:02 · ◇ session`.
- An agent's cursor is its cap, bobbing only while drawing. A "hands" filter dims everyone else's marks.
- Founder decision: content colour. Recommendation: paper stocks (kraft, white, fold, carbon), no hues.

## 3. One surface, two layers
- Paper layer: stickies, shapes, frames, images, sketches.
- Live layer: kernel- and Paradigm-fed nodes (session, loop, task, CI run, agent), status by mark (✓ ✕ ● … ·) and edge weight, the loop-graph grammar.
- Agents place automatic nodes in a ruled tray at the board's edge; the founder drags one out to adopt it.
- The active-context display = a default board per session, mostly live layer.

## 4. The crafted device: pin and shadow
- Every item is a scrap pinned to the ground; the pin head is the author's seal. Day: paper pin. Night: a phosphor point.
- The shadow tells time (from the gnomon itself): a live node's hard offset shadow lengthens as its data goes stale. Reduced motion keeps length, drops transition.
- Images: paper tape by day, glow outlines by night (brackets mean a key at night).
- Excalidraw's hand-drawn font and roughness are a template tell: reskin fully or use it only as an engine.

## 5. Voice now, gesture and VR later
- Store structured nodes in board units with explicit relations (in frame, connected to, near), not pixels; layers map to depth in 3D later.
- Every node gets a handle word (kernel handle words) so speech can point at it.
- Every action is a named verb (place, connect, group, point, focus) callable from any input.
- Keep "focus" separate from hover so gaze or pointing can resolve "this". Nothing hover-only.
- Board edits are reversible, so voice may make them under the trust ladder; kernel-touching actions stay hand-only.

## 6. Prior art
- a-star right: infinite canvas, typed nodes and connections, minimap, command palette, pipeline as a drawing. Wrong: a canvas of boxed mini-app widgets (a dashboard, not an idea space); stock Tailwind/Lucide look; hue means node kind; no authorship; no line between model content and controls.
- Constellation right: nodes born as you talk; the scanning comet flying to where Claude is about to work (Gnomon's version: the agent's cap travelling to its spot); glyphs carry type; light spent only on what's new; calm copy. Wrong for Gnomon: the agent arranges and you watch (no co-authorship); hue per type; full-bleed map would cover kernel regions; 800ms births too slow.
