02 · The problem

Git took a photograph. It froze the bytes.

Every other version control system still versions the artifact, not the meaning. It records that characters moved on disk — never what those characters were supposed to mean, who decided it, or what depended on the decision. The text is preserved with perfect fidelity. The intent evaporates.

The hash moves iff the meaning moves.

Down to the function. Warpline doesn't stop at components — it lifts every TypeScript function, method, and class into the same WARP. A function's identity is its structure and written types, never its name or its formatting. Rename getUser → fetchUser, move it to another file, reformat it: same essence, zero delta. Change what it does — one operator, one missing await — and the essence moves. Code becomes meaning the same way symbols do, and the two share one fabric.

10 · The reckoning with git

Git is bulletproof. So is Warpline — it just versions the right thing.

A replacement has to clear the bar git already set. So first we honor what git does brilliantly — then we name what it can't see, and prove Warpline keeps every guarantee while it gains eyes.

What git does — and does brilliantly.

  • A content-addressed Merkle DAG that is tamper-evident — history can't silently corrupt.
  • Fully distributed, with no central authority.
  • Durable and offline-verifiable — every clone can check its own integrity.
  • Universal — it versions any bytes, in any language.
  • Battle-tested over 20 years, on nearly every codebase alive.

These are not features to beat. They are guarantees to keep.

Guarantees we keep

Merkle integrity — tamper-evident, over meaning
Fully distributed — no central authority

Offline-verifiable — every clone proves itself

Just as bulletproof · the parity promise

Warpline keeps every git guarantee, by construction — a tamper-evident Merkle DAG (over meaning instead of bytes), content-addressed integrity, fully distributed and offline-verifiable, no data loss, complete durable history.

We don't trade reliability for intelligence — we keep git's spine and give it eyes.

Anything Warpline can't yet lift to meaning is carried as an opaque, content-addressed blob (git-grade) — graceful degradation, never silent loss.

11 · Replacement, not companion

Git is where you come from. Not where truth lives.

The WARP — the meaning store — is the repository and the source of truth. Warpline is a replacement, not a companion. Git keeps two jobs, neither foundational: backfill in, export out.

  • WARP — the meaning store — IS the repository and the source of truth. Warpline is a replacement, not a companion.
  • BACKFILL — import an existing repo's full history into the WARP (the same ABSORB run over history), so you adopt without losing a day.
  • EXPORT — warpline export --git weaves a conventional git repo for CI, GitHub, and teammates who haven't switched — an output format, not a dependency.
  • Dual-write is a build-time validation harness: while Warpline matures it writes both, and the live Convergence / Divergence Oracle scores WARP's predicted merges against git's actual results. WARP earns confidence against reality, then the scaffold retires. It is how we prove it, not what we ship.
  • Honest: Warpline is experimental; the Oracle is the discipline that lets meaning earn the seat git holds today.

The WARP is the truth. Git is an onramp and an exit.

The what — the pieces.

The why.

Git versions bytes. In a world where most code is authored by agents you didn't supervise, the unit that matters is meaning + accountability. That's a change of the thing being versioned — structural, not a feature you can bolt on.

The how — the object model.

  • Content-addressed semantic objects in a Merkle DAG.
  • Identity = the hash of meaning (kind + contract + edges-by-target-hash), never name or path.
  • Bytes are a regenerable projection, not the source.
  • The round-trip law absorb(weave(W)) ≡ W is the correctness invariant, checked continuously.
  • Real polyglot code is hosted via fidelity-tiered lenses + a meaning-coverage metric, with opaque spans for anything not yet liftable — graceful degradation, never silent loss.
